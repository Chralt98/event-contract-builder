# Drafting specification

Use this reference for a new event, a source-review alternative, or selection
of an existing draft.

## New-event draft

Write concise, conversational Yes/No questions about a specific future event
within a defined time frame. Preserve supplied events, thresholds, options, and
dates; never invent a missing one. Questions must be 10–200 characters and end
with `?`. If the event, outcome, or time frame is materially unclear, ask for
it and do not submit.

Produce at least three distinct selectable units: one direct interpretation
and at least two close reformulations, measurable proxies, or better-specified
interpretations that preserve the user's intent. A grouped unit counts once;
an optional template is additional and never replaces those three units.

- **Binary:** one Yes/No question.
- **Scalar:** one question per non-overlapping range, covering the plausible
  space so exactly one should resolve Yes.
- **Categorical:** one question per mutually exclusive option.
- **Template:** one placeholder-bearing question plus finite allowed values,
  only under the invariance rule below.

A scalar, categorical, or template unit is always selected as a whole.

## Template invariance

Use a template only for at least two related instances with stable wording.
Replace a narrow finite parameter with a descriptive placeholder such as
`<date>` or `<candidate>` and list only explicit values supported by the input
or concrete draft. Every placeholder has exactly one same-named variable;
variables appear in placeholder order, names and values are unique, and no
variable is unused. Combine dependent values into one placeholder rather than
implying invalid combinations.

Instantiate every allowed value and meaningful combination before submission.
All instances must retain the same qualifying predicate, interpretation,
jurisdiction and legal/compliance treatment, authoritative source hierarchy,
formula, procedure, and methodology. Otherwise split them into separate units.
Never use broad wildcard placeholders or add values merely to create a
template. Selection never instantiates one template value.

## Source-review alternative

When source review reports missing primary coverage or no independent fallback,
propose one nearby, proxy, or better-specified unit that preserves the original
intent but can use at least two independent source agencies. Return only the
new display-question unit. Do not silently replace the original, define its
terms, or treat it as selected.

## Output detail

Keep units in drafting order. The follow-up asks which unit to use or revise
and identifies term definition as the next stage. Never summarize or renumber
the rendered draft.
