# Define background information

Read
[references/background-information-spec.md](references/background-information-spec.md)
for the content and source standard.

1. Require one exact unit with approved resolution criteria.
2. Research durable explanatory context and draft the complete background
   payload without changing any approved stage.
3. Call `submit_background_information` once and present the complete rendered
   review. Resubmit the complete payload after requested changes.
4. After explicit approval, approve `background_information` and show the
   server-defined output menu. Run `define-relevant-news` only if the user
   chooses its optional menu item.

Follow the server-wide language, metadata, rendering, export, and approval
rules.
