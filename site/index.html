From idea to specification

Each stage makes one part of the outcome clearer.

Start with an event in chat. Foresight prepares a draft for each stage in the MCP App, then waits for your review and approval before it continues. The usual path is shown here; you can open any stage to review it.

01 · Question

Draft one clear question

Turn the event into a self-contained forecast question, with values or a condition when the outcome needs them.

02 · Terms

Clarify what matters

Define only ambiguous terms that could change how the question is interpreted. This stage can be empty when none need a special definition.

03 · Sources

Rank resolution sources

Choose authoritative sources, put the strongest source first, and specify fallbacks if the first source is unavailable.

04 · Criteria

Define how it resolves

Write one complete, source-grounded rule for Yes or No, including the deadline and any important edge cases.

05 · Background

Add durable context

Give readers neutral, factual background that helps explain the event without changing the resolution rule.

06 · Optional News

Follow relevant updates

Choose whether to research a short, source-linked news timeline. News is optional context and does not change the criteria.

✓

Human review at every stage

You decide when a draft is approved.

The MCP App is where you read and edit the current draft. Approval and progression happen in your chat, so generated content stays pending until you accept it.

Resolution Criteria

Resolve Yes if, by 23:59 UTC on , the latest Artificial Analysis Intelligence Index publicly shown on the official leaderboard, using its published provider labels: Google for Google (Gemini), Meta for Meta (Llama), SpaceXAI for xAI (SpaceXAI on Index), and Alibaba for Alibaba (Qwen); the other named values use their corresponding publisher labels. This shows that this value’s highest model score equals the highest score on the same version. For Other, combine all provider labels not assigned to another value and use their highest score. If providers tie for the highest score, each matching value resolves Yes.

Resolve No if the provider’s highest score is below the Index-wide highest score, or if it has no scored model on that version. If no usable Index version is public by the deadline, resolve every value No. Later publications do not change the result.

The resolution source for this question is the Artificial Analysis Intelligence Index leaderboard. This question will resolve based on which provider values have the highest model score on the latest Index version available by the resolution deadline.

Background

The Artificial Analysis Intelligence Index is a composite measure built from multiple evaluations of AI model capabilities. Its published leaderboard shows an Index score and provider for each evaluated model.

Artificial Analysis updates the included evaluations and methodology over time. The criteria use the latest version available at the deadline so every provider is compared on the same basis.

For the official leaderboard, see Artificial Analysis Intelligence Index.
